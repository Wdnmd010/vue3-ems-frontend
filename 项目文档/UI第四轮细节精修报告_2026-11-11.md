## 二、四项具体调整

### 1. 图标风格统一（快捷操作）

- 容器：**深色圆角方形** 40×40，圆角 8px（`--radius-md`），底色 `#2d2d37`。原先的白底圆形已按要求替换。
- 图标：Element Plus 线性图标，字号 20px，**紫色 `#a47aff` 为主**；Excel 导入 / 导出用**蓝色 `#3298f3`** 区分「数据处理类」与「页面跳转类」。
- 间距：容器与文字 10px，四个入口完全一致（同一份 CSS，无逐个覆盖）。
- 其余图标位置（品牌 logo 32px、导航 16px、卡片标题锚点 24px、统计卡 44px、分页箭头 16px）本来就是同一套 Element Plus Icons，无 Emoji、无混用图标库。

### 2. 统计卡尺寸

| 项 | 调整前 | 调整后 |
|---|---|---|
| 卡片高度 | 89px | **105px** |
| 内边距（上下） | 18px | 22px |
| 图标容器 | 40px | 44px |
| 数值字号 / 字重 | 28px / 700 | **32px / 700** |
| 标题与数值间距 | 3px | 6px |
| 数字字体 | — | `tabular-nums`（位数对齐不跳动） |

高度增加来自内边距 + 文字间距 + 字号三处，不是单纯拉高卡片。手机端（≤767px）单独回落到内边距 18/16px、数值 28px，避免两列布局拥挤。

### 3. 顶部导航

- 顶栏 `.topbar` 由 `display:flex` 改为 `grid-template-columns: minmax(0,1fr) auto minmax(0,1fr)`，导航放在中间的 auto 列。
  - 原因是原写法里 `margin: 0 auto` + 右侧 `margin-left: auto` 会让三段平分剩余空间，导航实际偏左。
- 实测水平中心：1440 → 720（窗口中心 720）、1024 → 512、820 → 410、640 → 320、390 → 195，**全部精确居中**。
- 导航项间距 6→10px，胶囊高度 38px、内边距 18px、字号 14px，整体更舒展。
- 选中态仍是白底黑字，未选中仍是透明底 + `#a6a6b0`；顶栏无独立背景色。
- 左右两侧：品牌靠左（`justify-self:start`）、用户信息靠右（`justify-self:end`），窄屏不会重叠（640/390 下品牌文字与用户名自动隐藏，仅留图标）。

### 4. 字体层次

| 层级 | 规格 |
|---|---|
| 页面标题（员工管理 / 部门管理） | 20px / 700 / `#f5f5f7` |
| 首页欢迎标题 | 28px / 600 |
| 统计数值 | 32px / 700 |
| 卡片标题 | 16px / 600 |
| 表格表头 | 12.5px / 600 / `#a9a9b4` |
| 表格正文 | 14px / 400 / `#e0e0e7` |
| 辅助说明（欢迎副标题、快捷操作描述） | 11.5~13px / 400 / `#92929d` 系 |

主次差距靠「字号 + 字重 + 明度」三层拉开，没有把所有文字统一放大或加粗。

## 四、遗留与说明

1. **分页第 2 页**仍无法在真实界面验证（库里 10 条数据、每页 10 条，只有 1 页）。
2. **快捷操作图标配色**：紫色 2 个（新增员工、部门管理）、蓝色 2 个（Excel 导入 / 导出）。如果你希望蓝色只留 1 个，把 `quickActions` 里导出项的 `tone` 改回 `primary` 即可，只影响一行数据。
3. 统计卡在 390px 下两列（每列约 173px），图标 44px 已接近该宽度的上限；若后续要在手机端加环比等文字，需要把图标降到 36px 或改为上下布局。
